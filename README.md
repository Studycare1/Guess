# 📚 Guess Paper - Book View

Interactive book reader for guess papers with glassmorphism design.

## 🌐 Live
https://studycare1.github.io/Guess/

## 📤 Upload Images
Just upload images to `images/<subject>/` — auto-loaded via GitHub API!

Subjects: biology, biology12, chemistry, physics, maths, hindi, english, urdu

## ✨ Features
- Glassmorphism + Neumorphism UI
- Dark/Light/Auto theme
- Search, sort, filter
- Book viewer with zoom, rotate, fullscreen
- Thumbnail strip + jump to page
- Bookmark, slideshow, share, download
- Keyboard shortcuts
- Preload adjacent pages
- Touch swipe navigation
